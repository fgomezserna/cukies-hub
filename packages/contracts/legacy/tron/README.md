# Fuentes legacy TRON

Las ocho direcciones mainnet, owners y hashes observados estan en el
[registro canonico](../../../../docs/legacy-marketplace/contracts.json) y su
[evidencia fechada](../../../../docs/legacy-marketplace/evidence/2026-09-07-contracts.json).

Las fuentes verificadas aun no se han recuperado. Las ABI existentes se
conservan en sus rutas actuales; no se presentan como source Solidity ni se
copian contratos BSC asumiendo equivalencia con TVM.

Cada bundle recuperado ira en una carpeta por rol, conservando dependencias,
licencias, compilador/opciones, address, deploy tx/bloque y procedencia. Nile
y los fixtures Stage se mantendran separados de estos contratos mainnet.
